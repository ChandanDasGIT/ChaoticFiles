This is the architecture of ChaoticFiles

The three layers: frontend/ (QML) talks to wrapper/ (Qt C++), and wrapper/ talks to backend/ (plain C++).
Left out: build/, build-release/, AppDir/, dist/ and tools/ (generated or downloaded, not part of the code), and
.claude/ (private notes, ignored by git).

ChaoticFiles/
├── .github/                                // GitHub settings
│   └── workflows/                          // automatic jobs
│       └── release.yml                     // a v* tag builds on Ubuntu 22.04 and publishes the release
├── backend/                                // pure C++20 engine, no Qt: built as its own static library, fileengine
│   ├── apps/                               // installed apps
│   │   ├── desktopapps.cpp                 // parses Exec lines without a shell, starts apps
│   │   ├── desktopapps.h                   // reads .desktop files; apps for a file type, default apps, the terminal
│   │   ├── filetypegroups.cpp              // the file types the Default Apps panel offers
│   │   ├── filetypegroups.h                // FileTypeGroup and FileTypeChoice, by category
│   │   ├── localdefaults.cpp               // copies the system's list once; edits only its own
│   │   └── localdefaults.h                 // this app's own mimeapps.list
│   ├── archive/                            // archives
│   │   ├── archiver.cpp                    // picks the program by extension; removes a failed archive
│   │   └── archiver.h                      // compress and extract through tar, zip, unzip and 7z
│   ├── btrfs/                              // btrfs details
│   │   ├── btrfsinfo.cpp                   // FIEMAP and INO_LOOKUP ioctls; needs no root
│   │   └── btrfsinfo.h                     // subvolume, extents, shared and exclusive space
│   ├── contentinfo/                        // what is inside a file
│   │   ├── archiveinfo.cpp                 // counts through tar or 7z
│   │   ├── contentinfo.cpp                 // MIME type and type description, then the matching reader
│   │   ├── contentinfo.h                   // namespace ContentInfo: one reader per kind of file
│   │   ├── elfinfo.cpp                     // reads ELF headers: architecture, libraries, interpreter, stripped
│   │   ├── imageinfo.cpp                   // reads image headers and EXIF
│   │   ├── mediainfo.cpp                   // audio and video through ffprobe
│   │   ├── pdfinfo.cpp                     // PDF details through pdfinfo
│   │   └── textinfo.cpp                    // lines, words, characters, line endings
│   ├── directory/                          // reading a folder
│   │   ├── directorylister.cpp             // reads, sorts, and also lists the Trash and Recent
│   │   └── directorylister.h               // listDirectory, and DirectoryLister, which runs it on a thread and can be cancelled
│   ├── diskspace/                          // free space
│   │   ├── diskspace.cpp                   // asks statvfs
│   │   └── diskspace.h                     // DiskSpace and readDiskSpace
│   ├── drives/                             // disks
│   │   ├── drives.cpp                      // lsblk and udisksctl
│   │   └── drives.h                        // what is plugged in; mount and unmount
│   ├── entry/                              // one file or folder
│   │   ├── entry.cpp                       // asks statx; a link takes its kind and size from its target
│   │   └── entry.h                         // Entry, EntryKind, FileCategory, readEntry
│   ├── fileflags/                          // lsattr flags
│   │   ├── fileflags.cpp                   // the FS_IOC_GETFLAGS ioctl, for regular files and folders only
│   │   └── fileflags.h                     // FileFlags::read
│   ├── fileops/                            // small changes to the disk
│   │   ├── fileops.cpp                     // nothing here overwrites; removeTree never follows links or crosses disks
│   │   └── fileops.h                       // new file, new folder, link, rename, delete, protected folders
│   ├── filetype/                           // what kind of file
│   │   ├── filetype.cpp                    // table of extensions; does not read the file
│   │   └── filetype.h                      // detectFileType and categoryName
│   ├── foldericons/                        // the icon someone chose for a folder
│   │   ├── foldericons.cpp                 // kept in the user.chaoticfiles.icon attribute on the folder
│   │   └── foldericons.h                   // read, write, and the icon and colour in the value
│   ├── folderscan/                         // adding up a folder
│   │   ├── folderscan.cpp                  // walks without following links
│   │   └── folderscan.h                    // counts, sizes, largest files
│   ├── folderview/                         // what one tab shows
│   │   ├── folderview.cpp                  // hiding, filtering, click modes, keyboard movement, type-to-select
│   │   └── folderview.h                    // sorted, filtered rows and the selection, kept by path
│   ├── format/                             // text for the screen
│   │   ├── format.cpp                      // its implementation
│   │   └── format.h                        // namespace Format: sizes, dates, counts
│   ├── hashing/                            // file hashes
│   │   ├── hashing.cpp                     // one pass over the file for all of them
│   │   └── hashing.h                       // MD5, SHA-1, SHA-256, SHA-512, BLAKE3
│   ├── magic/                              // detailed file types
│   │   ├── magicfile.cpp                   // dlopen of libmagic.so.1
│   │   └── magicfile.h                     // libmagic, loaded when needed, so it is optional
│   ├── mimetypes/                          // the system's list of file types
│   │   ├── mimetypes.cpp                   // reads shared-mime-info: globs, kinds, icons, descriptions
│   │   └── mimetypes.h                     // namespace MimeTypes: a type from a name, and what it is a kind of
│   ├── mounts/                             // mounted filesystems
│   │   ├── mounts.cpp                      // reads /proc/self/mountinfo
│   │   └── mounts.h                        // Mount and namespace Mounts
│   ├── navigation/                         // back and forward
│   │   ├── navigationhistory.cpp           // visit, goBack, goForward
│   │   └── navigationhistory.h             // the folders one tab has visited
│   ├── network/                            // NAS and servers
│   │   ├── networkshares.cpp               // gio mount; the password goes through standard input
│   │   └── networkshares.h                 // SMB and SFTP through gvfs
│   ├── pathbar/                            // the address bar's logic
│   │   ├── pathbar.cpp                     // handles ~, relative paths and file:// addresses
│   │   └── pathbar.h                       // namespace PathBar: split, parent, subfolders, resolve, suggestions, the Trash and Recent locations
│   ├── permissions/                        // permissions
│   │   ├── permissions.cpp                 // reads the binary ACL and capability formats
│   │   └── permissions.h                   // names, rwx text, ACLs, capabilities
│   ├── places/                             // the sidebar's logic
│   │   ├── places.cpp                      // reads user-dirs.dirs and /proc/self/mountinfo
│   │   └── places.h                        // namespace Places: user folders and mounted drives
│   ├── process/                            // other programs
│   │   ├── process.cpp                     // fork and exec, never a shell
│   │   └── process.h                       // run a program and collect its output, or start one by itself
│   ├── properties/                         // the properties report
│   │   ├── properties.cpp                  // General, Permissions, Filesystem, Attributes, Link, Btrfs, Contents
│   │   ├── properties.h                    // namespace Properties: collect every section
│   │   └── propertyreport.h                // PropertyRow and PropertySection
│   ├── recent/                             // recent files
│   │   ├── recentfiles.cpp                 // its implementation
│   │   └── recentfiles.h                   // this app's list, and other apps' recently-used.xbel, read only
│   ├── search/                             // searching
│   │   ├── filesearch.cpp                  // sends matches in batches; no links, one disk
│   │   └── filesearch.h                    // FileSearch::run walks a folder tree
│   ├── shortcuts/                          // keyboard shortcuts
│   │   ├── shortcutmap.cpp                 // the default keys; a key belongs to one action only
│   │   └── shortcutmap.h                   // which keys do what
│   ├── sorting/                            // ordering
│   │   ├── sorting.cpp                     // natural order, folders first
│   │   └── sorting.h                       // SortKey, SortSettings, naturalCompare, sortEntries
│   ├── tabs/                               // the open tabs
│   │   ├── tabmanager.cpp                  // open, close, move, reopen
│   │   └── tabmanager.h                    // Tab (history and FolderView) and TabManager
│   ├── tasks/                              // background work
│   │   ├── backgroundjob.cpp               // its implementation
│   │   └── backgroundjob.h                 // a thread that is never waited for, and can be cancelled
│   ├── thumbnails/                         // thumbnails
│   │   ├── thumbnails.cpp                  // names in the cache; video and PDF through other programs
│   │   └── thumbnails.h                    // the shared thumbnail cache
│   ├── transfer/                           // copy and move
│   │   ├── transfer.cpp                    // conflicts, merging, reflinks, temporary files, pause and cancel
│   │   └── transfer.h                      // Transfer: the safety rules are at the top of this file
│   ├── trash/                              // the shared Trash
│   │   ├── trash.cpp                       // follows the freedesktop.org Trash specification, on every disk
│   │   └── trash.h                         // namespace Trash: move in, restore, list, empty
│   ├── undo/                               // undo
│   │   ├── undostack.cpp                   // keeps the last 50 steps
│   │   └── undostack.h                     // what was done and how to take it back
│   ├── update/                             // the rules of an update, no network
│   │   ├── update.cpp                      // versions, manifest, Ed25519 check, the swap script, the window lock
│   │   └── update.h                        // namespace Update
│   ├── watcher/                            // noticing changes
│   │   ├── folderwatcher.cpp               // inotify on its own thread, groups bursts of changes
│   │   └── folderwatcher.h                 // calls back when a folder changes
│   └── xattrs/                             // extended attributes
│       ├── xattrs.cpp                      // llistxattr and lgetxattr; never follows links
│       └── xattrs.h                        // namespace Xattrs: read them all, or one
├── dependencies/                           // third-party code

│   │   ├── blake3.c                        // unchanged
