ChaoticFiles is a Qt 6 / QML file manager for Linux. The engine is plain C++20 and does not depend on Qt.

Browsing
- Folder list with name, date modified, type and size.
- Open folders with a double click or Enter. Open files in their default app.
- Back, forward, up and refresh, with buttons, Alt+Left/Right/Up, F5 and the side buttons of a mouse.
- Sort by any column; folders stay first. Natural order: file2 comes before file10.
- Hidden files on or off with Ctrl+H.
- Select with click, Ctrl+click, Shift+click, the arrow keys, Ctrl+A, and by typing a name.
- A folder refreshes by itself when something in it changes.
- Clear messages for folders you can't open, missing folders and broken links.
- Folders are read on a background thread, so a huge or slow folder does not freeze the window.

Tabs
- Windows 11 style tabs in the title bar.
- New tab Ctrl+T, close Ctrl+W or middle click, switch with Ctrl+Tab, reopen with Ctrl+Shift+T.
- Drag a tab to reorder. Tabs shrink as more open, then the strip scrolls with the wheel.
- Each tab has its own folder, history, sorting, selection and scroll position.
- Drop files on a tab to put them in its folder.
- Middle click a folder, or right click it, to open it in a new tab.

Address bar
- Every folder in the path can be clicked.
- The arrow after a folder lists its subfolders.
- Click the empty part or press Ctrl+L to type a path. ~ works, and folders are suggested as you type.
- Long paths collapse into a "…" button.

Views and search
- Details and grid views. Ctrl+1, Ctrl+2. Ctrl+wheel changes the grid size.
- Thumbnails for images, video and PDF, in the cache other Linux apps share.
- Rubber band selection: drag from an empty part of the list or grid.
- Dragging shows what is being dragged, as a stack with a count when it is several items.
- Folders can have their own icon and colour: Change Icon in the right click menu. It follows the folder when it is renamed or moved.
- Preview panel (F3): a picture or the start of the text of the current file.
- Typing in the list jumps to a name. Pressing the same letter again goes to the next name starting with it.
- Ctrl+F filters the folder as you type. All Subfolders searches everything below it, showing each result's folder.

Sidebar and status bar
- Home, Recent, the standard user folders, the file system, the Trash.
- Pinned Folders: drop a folder on the heading, or use Pin to Sidebar in its right click menu. It stays where it is on the disk.
- Drives update by themselves. Click one that is not mounted to mount it; right click to unmount.
- NAS and servers: Connect to Server in the gear menu, for SMB and SFTP. Passwords are not stored.
- Recent shows files opened here and in other Linux apps.
- Item count, selection count and size, free disk space.

Properties (Alt+Enter)
- General: every date to the nanosecond, size and size on disk, full and real path.
- Permissions: owner, group, mode, special bits, what you can actually do, ACLs, capabilities.
- Filesystem: inode, device, links, blocks, mount, filesystem and its options, disk space, file flags.
- Attributes: every extended attribute, including the SELinux context.
- Btrfs: subvolume, extents, compressed extents, shared and exclusive space.
- Link: target, final target, broken or not, the whole chain.
- Content: MIME type, the same description as the file command, and details by kind: text, images with EXIF,
  audio and video, PDF, programs, archives.
- Folders: total size, counts and largest files, worked out in the background. Several items: totals and shared values.
- Hashes on request: MD5, SHA-1, SHA-256, SHA-512, BLAKE3, with progress and cancel.
- Every value can be copied, and Copy All gives a plain text report.

File operations
- New folder, new file, rename (F2), create link. None of these ever replaces an existing item.
- Cut, copy and paste, also with other Linux file managers. Cut items are shown faded.
- Drag and drop onto folders, the empty part of the list, the sidebar and tabs. Same disk moves, another disk
  copies; hold Ctrl to copy or Shift to move.
- Progress for each running job, with pause and cancel. Several jobs can run at once.
- "Already exists" dialog: replace, skip, keep both, or cancel, for one item or all of them.
- Copies use reflinks on btrfs, so they are instant and take no extra space.
- A cancelled or failed copy leaves no half-written file, and a replaced file stays until the new one is complete.
- A move across disks deletes the original only after everything has arrived.
- Move to Trash (Del), restore, empty, delete permanently (Shift+Del) with a warning.
- Restore All and Delete All buttons at the bottom of the Trash.
- The Trash covers every disk, and shows where each item came from and when it was deleted.
- /, the folders directly under it, and Home can't be trashed or deleted.
- Undo (Ctrl+Z) for rename, move, Trash, new items and copies. Undoing a copy moves it to the Trash.
- Open With, showing the apps that fit with their icons, or all apps with a search box, and it can make one the default. Open Terminal Here.
- Compress to .tar.gz, .tar.xz, .tar.zst, .zip or .7z. Extract always goes into a new folder.

Interface
- Dark, light and system themes. System follows the desktop's dark or light preference.
- Draws its own title bar. Window buttons are off by default on tiling desktops, and can be switched on.
- Right click menus on files, empty space and sidebar items. Copy Path.
- Settings window (Ctrl+,). Keyboard shortcuts open in their own panel, editable, with Restore Defaults.
- Default Apps in the settings: choose the app for each file type, by category, or for a whole category at once.
- Default app changes can be system-wide, or for this app only. This app keeps its own list, which starts as a copy of the system's. The system's file is never changed in that mode.

Starting up
- Settings > Opens to: Home, Last Tabs, or a folder you choose. A folder that is gone opens Home, and folders named on the command line go first.

File types
- Types come from the system's own list, by name first and by content when the name can't tell, so a QML file is a QML file and not plain text.
- Icons come from your icon theme when it has one for that type, so QML, C++, Rust and others each look like themselves. Otherwise the app draws its own.
- Open With and Default Apps go by the same types, and a type with no default of its own uses what it is a kind of.

Updates
- A green dot in the status bar shows a new version. Clicking it opens Settings > About.
- Checks once a day if the switch is on. Failed checks stay silent, and Check now reports the result.
- Update now downloads, checks the signature, waits for running operations, restarts and reopens your tabs.
- If the new version does not start, the old one comes back and the app says so.
